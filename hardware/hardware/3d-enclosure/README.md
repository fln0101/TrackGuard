3D Enclosure Design

This folder documents the mechanical enclosure developed for the TrackGuard prototype.

Design Tool

CAD software: Onshape

Design Objectives

Provide a compact housing for the electronic hardware.

Allow access to the USB-C connector.

Provide suitable ventilation around the BME280 environmental sensor.

Secure the electronics inside the enclosure.

Support a separate body and lid.

Design Status

The enclosure design is in development. Component positions, battery dimensions, internal clearances, USB-C alignment, and sensor ventilation must be verified before manufacturing.
