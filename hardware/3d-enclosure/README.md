TrackGuard 3D Enclosure Design

Overview

This folder documents the 3D enclosure designed for the TrackGuard monitoring system.

CAD Software

Onshape

Design Objectives

House the electronic hardware securely.

Provide access to the USB-C connector.

Allow ventilation around the BME280 environmental sensor.

Accommodate the PCB and battery.

Use a separate enclosure body and lid.

Current Status

The enclosure is under development. Component positions, internal clearances, USB-C alignment, sensor ventilation, and battery fit must be verified before manufacturing.
